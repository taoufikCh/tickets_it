Liaison avec GLPI

{% if cfg['glpi_enabled']=='1' and cfg['glpi_app_token'] and cfg['glpi_user_token'] %}Envoi activé{% else %}Envoi désactivé{% endif %}

Permet d'envoyer un ticket vers GLPI (version 10) avec le bouton « Envoyer vers GLPI » de la fiche ticket. L'envoi se fait ticket par ticket, dans un seul sens : Tickets IT → GLPI.

Préparer GLPI (à faire une seule fois)
  1. Dans GLPI : Configuration → Générale → API : activer l'API REST et la connexion avec un jeton externe.
  2. Sur la même page, ouvrir le client API « full access from localhost » (créé par défaut) et copier son jeton d'application. Il autorise 127.0.0.1, adapté à GLPI et Tickets IT sur le même ordinateur.
  3. Créer dans GLPI un compte dédié (par exemple tickets-it) avec un profil limité à la création de tickets. Dans ses préférences (« Clés d'accès distant »), générer le jeton d'API : c'est le jeton utilisateur.
  4. Coller l'adresse de GLPI et les deux jetons ci-dessous, puis cliquer sur « Tester la connexion ».
